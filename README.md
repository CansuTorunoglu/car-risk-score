# car-risk-score

## Goal
We are building a live-usable data product called **Used Car Listing Risk Score System** using the Craigslist cars/trucks Kaggle dataset.

The product will analyze second-hand car listings and produce:
- Trust score
- Risk level
- Risk reasons
- Buyer recommendations
